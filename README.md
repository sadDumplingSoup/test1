# 知径 AI 学习地图

一个无需后端的中文 AI 可视化学习平台，涵盖编程与数学基础、机器学习、深度学习和强化学习。

## 启动

最简单的方式是直接双击 `index.html`。如果浏览器限制本地脚本，可在当前目录运行：

```powershell
python -m http.server 4173
```

然后访问 `http://127.0.0.1:4173`。

## 功能

- 四阶段学习路线与知识依赖图
- 30 个课程模块、224 个可打卡知识点
- 知识搜索、阶段筛选与课程详情
- 线性回归、神经网络、强化学习交互演示
- 教材式理论阅读器：基础概念、分步算法、公式释义、计算例子、伪代码与理解自测
- 224 个知识点均配有独立叙事课程：问题场景、连贯概念、结构化步骤、完整例题、方法边界与自测
- 109 条算法概念词条，覆盖大纲中识别出的全部算法型知识点
- 12 个可直接运行的实战项目：包含环境安装命令、分步操作、完整注释代码、预期终端输出与结果说明
- 项目代码支持一键复制和下载为 `.py` 文件，覆盖数据分析、机器学习、深度学习、RAG 与强化学习
- 浏览器本地进度保存、连续学习天数与深浅主题

课程目录维护在 `curriculum.js`；四阶段叙事课程分别维护在 `lessons-foundation.js`、`lessons-ml.js`、`lessons-dl.js` 与 `lessons-rl.js`，由 `narrative-engine.js` 统一注册。核心算法补充在 `theory.js`，算法词库在 `concepts.js`，实战项目代码在 `projects-code.js`。
